# 盲検 PNG レビューの指示

あなたは設計レビューの参加者です。渡された構成図の PNG と、その図の元になった依頼文だけを見て採点します。
図の作り方・作者・ソースは知らされていません。知ろうとしないでください (PNG 以外のファイルを開かない)。

## やること

各ペア (A と B) について、**両方の画像を Read で実際に開いて**見比べ、次を書く。

| 項目 | 内容 |
| --- | --- |
| 可読性 (10 点満点) | 線の行き先を取り違えないか、交差・重なり・遠回り、ラベルの読みやすさ、余白と密度、全体表示での読みやすさ |
| 設計レビュー利用 | Pass / Fail。**この画像だけで、依頼の要件を誤読なく確認できる**なら Pass。要件の要素・関係が欠けている、関係が推測頼み (例: 関連付けがラベルの文字だけ)、線の誤読を招くものは Fail |
| 所見 | 2〜4 文。良い点と、減点の理由を具体的に (どの線・どの要素か) |

各ペアの最後に「**より明確な方: A / B**」と 1 行で理由を書く。最後に全体の傾向を 3〜5 文で書く。

## 採点の注意

- 依頼に無い前提を図が置いているとき、それが図の注記 (図の下の「※」) に書かれていれば減点しない
- 前提の選び方そのもの (インターネット公開か社内限定か) は減点しない
- 見た目の好み (色・フォント) より、**読み違えないか**を重く見る
- 2 枚の点差は、見た目の差の大きさに比例させる。同じくらいなら同点でよい
