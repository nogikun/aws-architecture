# 配置と線 — 読みやすい図の決まり

archdraw は座標を書かせない。**読みやすさは「どの枠に入れるか」「並び順」「並べ方 (row / column)」で決まる。**
自動配置は「子を書いた順に詰める」だけなので、並びを考えるのは作者の仕事。

## 流れ

- 1 枚の図には主な流れが 1 本ある (利用者 → 入口 → アプリ → データ)。**主な流れを左 → 右に置く**
- 枠の中の流れは、枠の種類の既定 (AWS の VPC は上 → 下) か、`flow="down"` / `flow="right"` で決まる
- 各アイコンは、入口の面と出口の面が向かい合う (左から入って右へ、上から入って下へ)。線がアイコンを一直線に通り抜ける
- 流れに逆らう線 (中 → 外の戻り、応答) は自動で点対称の面を使う。行きと同じ面に乗る分は別の位置に分かれる

## 並び順で線を直す

- **線でつながる相手どうしを隣に置く。** 遠くへ伸びる線は、他のアイコンや線を横切る
- 1 つの要素から複数へ分かれる線 (ALB → 各 AZ のアプリ) は、分かれる先を同じ列・同じ行にそろえる。幹を共有して T 字に分かれる
- 同じ構成の繰り返し (AZ ごと、サーバー A/B/C) は、同じ順・同じ形にそろえる。違って見えると、構成が違うと読まれる
- 縦に並べたいものは `column`、横は `row`。枠を描かずに並べ方だけ変えたいときは `layout` 箱 (`d.row()` / `d.column()`)
- 上流の要素 (利用者、外部の入口) は左、下流 (データ、外部の送り先) は右

## 線を減らす (いちばん効く)

- **全体にかかる関係 (監視・ログ・認可・バックアップ) は、要素ごとに引かない。** それを囲む枠から 1 本の破線にまとめる
  (例: `app_group.to(datadog, "メトリクス (全サービス)", dashed=True)`)。線の端は枠でもよい
- 同じ相手への同じ種類の線が多いなら、代表の 1 本にしてラベルで補う (「各 AZ から」)
- **関係の種類を線種で分ける** (読み手はまず線種で関係を読む):

  | 関係 | 線 |
  | --- | --- |
  | 同期の通信 (HTTP、SQL、呼び出し) | 実線 + 矢印 |
  | 非同期 (キューに積む・キューから起動する、イベント、Publish) | **破線** + 矢印。SQS / Kafka を通る区間は両側とも破線 |
  | レプリケーション・バックアップ | 破線 + 矢印 (複製の向き) |
  | 関連 (WAF の関連付け、IAM ロール、オーソライザー、監視) | 破線 + **`arrow="none"`** (向きの無い関係に矢印を付けると、通信に見える) |
- 論理的な関連 (破線) の相手は、関連元の近くに置く。遠くへの長い破線は、実線を横切り、境界の外に見える

## 線のラベル

- 12〜16 字まで。プロトコルや操作 (`HTTPS`, `SQL`, `Publish`)。全部の線に付けない (ラベルが多いと重なる)
- 同じ内容 (ラベル + 線種) の線だけが、出口と幹を共有する。内容が違う線は別の位置から出る

## 枠

- 枠の面積は、中身に必要な面積の 1.5 倍まで (それ以上は `N-SPARSE`)。中身が少ない枠を、隣に合わせて引き伸ばさない
- 中身が無くラベル付きで線につながる `generic` は、外部システムを表す小さな実線の箱になる
- 並べ替えのための `layout` 箱は描かれない。その枠線上に要素を置かない

## キャンバス

- **縦長は禁止** (`N-ASPECT-PORTRAIT`)。16:9 は目安で、線の素直さを崩してまで合わせない
- 縦長になったら: 外の要素を左右に置く、並列の枠を横に並べる
- 横に長すぎたら (3:1 を超える): 外の要素を `column` の layout 箱に縦に積む
- 要素が 25 個を超えたら、図を分ける (全体図と詳細図) ことを検討する

## 接続口を固定する (最後の手段)

並び順で直らないときだけ `exit` / `entry` (top / right / bottom / left) で線の出口・入口の面を固定する。
固定すると経路探索の自由が減るので、1〜2 本までにする。

## アイコンの見た目

- AWS 公式アイコンは色付きのタイルなので、そのままでそろう
- 取り込んだセット (ロゴ・線画) は形も大きさもまちまち。並べてばらついて見えるなら `icon_style="tile"` で白いタイルに載せる
